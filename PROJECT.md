# Scratchpad

A playful, local-first IDE that looks like handwriting and doodles on paper. Type a request and the tiny agent stages a tool run, then opens a working artifact on the same canvas.

Built as a faithful interactive study of Kevin Ngo's napkin IDE shown in Sawyer Hood's X post. No framework, build step, accounts, paid APIs, or tracking.

## What works
- Animated request → plan → write → preview agent loop
- Three generated artifact modes: persistent todo app, data sketch, robot-studio landing page
- Local run history and persistent todos
- New-page flow, rerun, clear, prompt presets
- Responsive layout
